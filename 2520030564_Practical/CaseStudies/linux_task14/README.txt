Task 14 - Command History and Terminal Input

This program demonstrates Linux terminal input using termios.

Concepts demonstrated:
1. termios.h
2. struct termios
3. Canonical and non-canonical terminal modes
4. Escape sequences
5. Command history
6. Up-arrow history navigation
7. Down-arrow history navigation
8. Backspace input editing
9. Input buffer management
10. History command
11. Exit condition

The program stores previously entered commands and allows
the user to navigate through them using the arrow keys.
